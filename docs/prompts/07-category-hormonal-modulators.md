# Category image prompt: Hormonal Modulators

## Purpose
Create a digital, icon-led category card for the homepage explorer. This should not look like the hero images and should not use real-world product photography. The image must feel like a designed UI asset for a premium pharmacy marketplace.

## Shared category visual thread
- Visual system: virtual pharmacy category cards, like a polished motion-graphics key visual or app dashboard module.
- Palette: warm ivory `#fbfbf9`, herbal green `#536e2c`, deep forest `#182110`, sage `#e5ead2`, restrained amber `#b0822a`.
- Shared structure: softly rounded abstract card background, subtle radial gradient, fine grain, translucent grid, glassmorphism panels, and one large custom central icon.
- Shared motif: a thin herbal-green orbital ring and small amber signal dots appear in all four images.
- Icon style: custom 3D vector glyph, beveled glass/plastic material, soft shadows, not a stock icon, not Phosphor, not emoji.
- No real-world objects: no bottles, vials, pills, shelves, hands, labels, packaging, counters, or photographic scenes.
- No baked text, logos, brand names, UI labels, numbers, or readable marks inside the image.

## Image prompt
Create a premium digital category card background for a pharmacy marketplace category, Hormonal Modulators. Use a warm-ivory and sage abstract background with deep herbal-green gradient corners, soft grain, translucent grid lines, and layered glassmorphism panels. In the center, place a custom 3D vector icon that represents balance and modulation: three vertical rounded slider controls arranged inside a circular endocrine-like orbit, with the center slider slightly higher and connected by a gentle wave line. Build the icon from frosted sage glass, deep green bevels, and tiny amber calibration dots. The symbol should feel precise, balanced, medical, and digital, like a motion-graphics card for a premium pharmacy app. Avoid literal body anatomy or real-world medicine. Leave lower-left space for UI text overlay. No text or labels.

## Negative prompt
Real medicine, bottles, vials, pills, blister packs, syringes, hands, lab table, pharmacy shelves, anatomy diagram, endocrine glands, body silhouette, readable text, letters, numbers, logos, brand names, generic sliders icon, settings icon, emoji, flat icon pack, cold blue clinical interface, clutter, fake UI labels, watermark, AI artifacts, distorted shapes.

## Composition notes
- Icon should read as modulation and balance, not generic settings.
- Use a circular orbit around the sliders to connect it visually with the other cards.
- Keep amber dots minimal, like calibration points.
- Lower-left should be visually quiet for title and short line.
