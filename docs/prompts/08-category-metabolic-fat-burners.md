# Category image prompt: Metabolic and Fat Burners

## Purpose
Create a digital, icon-led category card for the homepage explorer. This should not look like the hero images and should not use real-world product photography. The image must feel like a designed UI asset for a premium pharmacy marketplace.

## Shared category visual thread
- Visual system: virtual pharmacy category cards, like a polished motion-graphics key visual or app dashboard module.
- Palette: warm ivory `#fbfbf9`, herbal green `#536e2c`, deep forest `#182110`, sage `#e5ead2`, restrained amber `#b0822a`.
- Shared structure: softly rounded abstract card background, subtle radial gradient, fine grain, translucent grid, glassmorphism panels, and one large custom central icon.
- Shared motif: a thin herbal-green orbital ring and small amber signal dots appear in all four images.
- Icon style: custom 3D vector glyph, beveled glass/plastic material, soft shadows, not a stock icon, not Phosphor, not emoji.
- No real-world objects: no bottles, vials, pills, shelves, hands, labels, packaging, counters, or photographic scenes.
- No baked text, logos, brand names, UI labels, numbers, or readable marks inside the image.

## Image prompt
Create a premium digital category card background for a pharmacy marketplace category, Metabolic and Fat Burners. Use a warm-ivory to sage gradient background with deep herbal-green depth, subtle grain, translucent grid lines, glassmorphism panels, and a refined motion-graphics look. In the center, place a custom 3D vector icon that suggests metabolism and energy without diet-culture imagery: a circular energy gauge formed by a clean green orbit, a small abstract flame-leaf shape in the middle, and two amber signal ticks. The icon should feel controlled, health-focused, and precise, not aggressive. Use frosted sage glass, deep green bevels, restrained amber highlights, and soft shadows. The image should be virtual and designed for a premium pharmacy UI, not a real product photo. Leave lower-left space for UI text overlay. No text or labels.

## Negative prompt
Real pills, bottles, vials, supplements, citrus, measuring tape, body before-after, scales, gym, bodybuilder, fire explosion, aggressive fitness ad, weight-loss claim text, photographic scene, pharmacy shelves, readable text, logos, brand names, generic flame icon, emoji, flat icon pack, neon orange overload, fake UI labels, watermark, AI artifacts, distorted gauge.

## Composition notes
- Icon should read as energy and metabolism, but remain calm and premium.
- The flame-leaf must be abstract and brand-safe, not a literal fire graphic.
- Use the same orbit, grid, glass panels, and amber dots as the other category cards.
- Lower-left stays quiet for category title and short line.
