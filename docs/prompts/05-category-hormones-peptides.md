# Category image prompt: Hormones and Peptides

## Purpose
Create a digital, icon-led category card for the homepage explorer. This should not look like the hero images and should not use real-world product photography. The image must feel like a designed UI asset for a premium pharmacy marketplace.

## Shared category visual thread
- Visual system: virtual pharmacy category cards, like a polished motion-graphics key visual or app dashboard module.
- Palette: warm ivory `#fbfbf9`, herbal green `#536e2c`, deep forest `#182110`, sage `#e5ead2`, restrained amber `#b0822a`.
- Shared structure: softly rounded abstract card background, subtle radial gradient, fine grain, translucent grid, glassmorphism panels, and one large custom central icon.
- Shared motif: a thin herbal-green orbital ring and small amber signal dots appear in all four images.
- Icon style: custom 3D vector glyph, beveled glass/plastic material, soft shadows, not a stock icon, not Phosphor, not emoji.
- No real-world objects: no bottles, vials, pills, shelves, hands, labels, packaging, counters, or photographic scenes.
- No baked text, logos, brand names, UI labels, numbers, or readable marks inside the image.

## Image prompt
Create a premium digital category card background for a pharmacy marketplace category, Hormones and Peptides. Use an abstract warm-ivory to sage gradient background with deep herbal-green depth in the corners, subtle noise, a fine translucent grid, and soft glassmorphism panels. In the center, place a custom 3D vector icon that suggests peptides and hormonal signaling: a clean molecular chain made of rounded nodes connected by short smooth links, wrapped by a thin orbital ring. The icon should be large, simple, recognizable at small card size, and made from frosted sage glass with deep green edges and tiny amber signal dots. Add faint waveform lines and soft glow accents to make it feel virtual, precise, and professional. The overall look should be a designed motion-graphics still, suitable for a premium pharmacy UI, not a real product photo. Leave enough calmer space in the lower-left for UI text overlay. No text or labels.

## Negative prompt
Photographic scene, real bottles, vials, syringes, pills, packaging, hands, pharmacy shelves, wood counter, lab table, readable text, letters, numbers, logos, brand names, stock icon, emoji, flat generic icon pack, Phosphor icon style, medical diagram with labels, cold hospital blue, neon sci-fi overload, clutter, fake UI, watermark, AI artifacts, distorted geometry.

## Composition notes
- Central icon should occupy about 45 percent of the card width.
- Keep the lower-left quiet for overlaid category title.
- Use a darker green gradient behind the icon for contrast, but keep the whole image light enough to match the Viana page.
- The orbital ring and amber dots must match the other category prompts so the set feels like one visual system.
