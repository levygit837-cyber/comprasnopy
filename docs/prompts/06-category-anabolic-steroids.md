# Category image prompt: Anabolic Steroids

## Purpose
Create a digital, icon-led category card for the homepage explorer. This should not look like the hero images and should not use real-world product photography. The image must feel like a designed UI asset for a premium pharmacy marketplace.

## Shared category visual thread
- Visual system: virtual pharmacy category cards, like a polished motion-graphics key visual or app dashboard module.
- Palette: warm ivory `#fbfbf9`, herbal green `#536e2c`, deep forest `#182110`, sage `#e5ead2`, restrained amber `#b0822a`.
- Shared structure: softly rounded abstract card background, subtle radial gradient, fine grain, translucent grid, glassmorphism panels, and one large custom central icon.
- Shared motif: a thin herbal-green orbital ring and small amber signal dots appear in all four images.
- Icon style: custom 3D vector glyph, beveled glass/plastic material, soft shadows, not a stock icon, not Phosphor, not emoji.
- No real-world objects: no bottles, vials, pills, shelves, hands, labels, packaging, counters, or photographic scenes.
- No baked text, logos, brand names, UI labels, numbers, or readable marks inside the image.

## Image prompt
Create a premium digital category card background for a pharmacy marketplace category, Anabolic Steroids, with a responsible and professional tone. Use a warm-ivory to muted sage gradient background with deep herbal-green corner shading, subtle grain, translucent technical grid, and layered glassmorphism panels. In the center, place a custom 3D vector icon that communicates controlled strength and pharmaceutical structure without showing bodies or injections: a shield-shaped glyph containing an abstract fused-ring molecular structure, simplified into clean rounded geometry. The shield is frosted sage glass with deep green bevels, restrained amber edge highlights, a thin orbital ring, and small amber signal dots. The mood should be secure, regulated, discreet, and premium. It should feel like a designed motion-graphics still for a modern pharmacy UI, not a real-world steroid photo. Leave lower-left space for UI text overlay. No text or labels.

## Negative prompt
Bodybuilder, gym, muscles, syringe, injection, needles, vials, ampoules, pills, real products, illegal lab, dark underground look, aggressive red lighting, photographic scene, pharmacy shelves, labels, readable text, logos, brand names, stock shield icon, generic superhero shield, emoji, flat icon pack, fake UI, watermark, AI artifacts, distorted molecules.
